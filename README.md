## 🚀 About Me

🔹 **Salesforce Developer with 6+ years** of experience in Apex, Lightning Web Components (LWC), Visualforce, Salesforce DX, and API integrations — designing and deploying custom applications and **ERP integrations** that improved operational efficiency and reduced system errors by **25%**.
